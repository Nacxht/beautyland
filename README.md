## Definition of Done (DoD)

Sebuah _User Story_ dinyatakan _Done_ apabila:

1. Semua _Acceptance Criteria_ telah terpenuhi
2. Kode sudah di-_merge_ ke _branch_ main melalui _Pull Request_ dan telah direview minimal 1 anggota
3. Fitur telah diuji olah QA/_Tester_
4. Tidak terdapat error yang mengganggu penggunaan fitur
5. _Card_/_Task_ pada GitHub Projects telah diperbarui menjadi _Done_
